Feito para mobilidade

O essencial, sem cerimônia.

Um menu direto para guardar, encontrar e preencher credenciais a partir do seu próprio dispositivo.

⌁

Leve e portátil

O README descreve execução em espaço de usuário, sem instalação tradicional e sem gravação no Registro do Windows.

⌨

Preenchimento rápido

Use a opção de auto digitação para enviar as credenciais à janela ativa por meio de teclas simuladas.

⟲

Recuperação descrita

O projeto documenta uma cópia local que pode ser usada para reconstruir os dados no pendrive quando necessário.

＋

Cadastre contas

Registre o site, o identificador e a senha; o README diz que a cópia local é atualizada ao adicionar credenciais.

▤

Consulte sua lista

Veja as entradas guardadas no índice do cofre usando os controles numéricos da interface.

⌫

Remova registros

Apague um registro pelo menu. A documentação diz que a exclusão também alcança os demais nós de armazenamento.

Guarde e use

Cadastre, consulte ou preencha credenciais pelas opções numeradas.

Sua cópia de segurança

Uma rota de recuperação local.

Além do arquivo principal no USB e de uma cópia oculta no próprio dispositivo, o README descreve um arquivo de recuperação no computador. Mantenha também uma cópia do executável e não perca a senha mestra.

Antes de confiar credenciais importantes ao cofre, avalie o projeto e valide o processo de recuperação para o seu próprio caso de uso.
%LOCALAPPDATA%\LocalStorage\fritadordecerebros3000\backup.dat

Caminho documentado no README. O funcionamento e a segurança das cópias não foram auditados independentemente.
