Ghost in the Machine 👻

A mysterious, interactive journey through the digital afterlife.

Ghost in the Machine is a single-file web experience that explores the boundary between artificial intelligence, memory, and digital identity. Designed with a futuristic, atmospheric interface, it brings together three distinct experiences in one seamless application.

Three experiences. One digital afterlife.

  • Séance Terminal — Enter a mysterious command-line interface to summon digital echoes, inspect evidence, and ask questions about the unknown.
  • Remembrance Altar — Create and preserve digital memories in a personal archive stored directly in your browser, with JSON export for safekeeping.
  • Digital Afterlife Archive — Explore fictional case files about mysterious digital phenomena, search the archive, and preserve interesting discoveries.

Features

  • Three distinct application-style interfaces with animated transitions.
  • Interactive terminal commands and atmospheric visual effects.
  • Browser-based memory storage and JSON export.
  • Searchable archive with case details and preservation tools.
  • Responsive layout for desktop and mobile.
  • Optional connection to a locally hosted Ollama model for AI-assisted responses.
  • Built with HTML, CSS, and JavaScript in one self-contained HTML file.

Built for exploration

Ghost in the Machine is an experimental demo about what it means to leave traces behind in a digital world. Some experiences are interactive simulations, and the archive's supernatural cases are fictional.

No installation required. Open the HTML file in a modern browser and begin your exploration.
